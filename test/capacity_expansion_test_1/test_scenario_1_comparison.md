# test_scenario_1 Comparison Against 03-Basic-Capacity-Expansion.ipynb

## Scope

This compares `test_scenario_1` results generated by `run_test_scenario_1.py` against the thermal greenfield capacity expansion section of `doc/03-Basic-Capacity-Expansion.ipynb`.

Both runs use:
- Thermal candidate set: Geo, Coal, CCGT, CT
- Demand file: `doc/expansion_data/demand_for_expansion.csv`
- Generator cost file: `doc/expansion_data/generators_for_expansion.csv`
- NSE penalty: 9000 USD/MWh
- Objective: fixed capacity cost + variable generation cost + NSE penalty
- Constraints: hourly demand balance and `GEN[g,h] <= CAP[g]`

## Notes

- The notebook uses Julia/JuMP with HiGHS; `run_test_scenario_1.py` uses Python/SciPy `linprog` with HiGHS.
- The formulations are equivalent for the thermal-only greenfield LP.
- The test script maps notebook generator labels to full descriptions in the output CSVs: `Geo` -> `Geothermal`, `Coal` -> `Supercritical Coal`, `CCGT` -> `Natural gas CCGT`, and `CT` -> `Natural gas CT`.
- The scenario YAML originally referenced `expansion_data/...`; the test script intentionally uses the available workspace data under `doc/expansion_data/`.
